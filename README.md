# الموقع البحثي وموسوعة المصطلحات الثقافية

موقع ثابت (HTML + CSS + JavaScript) بلا قواعد بيانات ولا خوادم، وبلا أي خطوة بناء.

## بنية الملفات

```
index.html          الصفحة الوحيدة للموقع (التنقل يتم داخلها)
assets/style.css    التصميم والألوان والخطوط
assets/app.js       منطق الموقع: البحث، الفهرس الأبجدي، عرض الصفحات
data/terms.js       مداخل الموسوعة  ← هنا تضيف مصطلحاتك
data/research.js    الأبحاث وبيانات الموقع (اسمك ونبذتك)  ← وهنا أبحاثك
papers/             (أنشئه) ضع فيه ملفات PDF لأبحاثك
```

## التجربة على جهازك

افتح `index.html` مباشرة في المتصفح، يعمل دون إنترنت (ما عدا الخطوط).

## إضافة مصطلح

افتح `data/terms.js`، انسخ أي كتلة `{ ... }` والصقها في القائمة، وعدّل الحقول.
انتبه إلى أن يكون `id` بحروف لاتينية وفريداً، وإلى الفاصلة بين الكتل.

## النشر المجاني على GitHub Pages

1. أنشئ حساباً على github.com.
2. أنشئ مستودعاً جديداً باسم `اسم-المستخدم.github.io` (عاماً Public).
3. ارفع جميع الملفات (Add file ← Upload files).
4. من Settings ← Pages اختر الفرع `main` ثم Save.
5. بعد دقيقة يصبح الموقع على: `https://اسم-المستخدم.github.io`

يمكن لاحقاً ربط نطاق خاص (مثل yourname.com) من الصفحة نفسها.
